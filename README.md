# 🎲 Ludo Game

एक शानदार Java में बना हुआ Ludo game जहाँ आप अपने दोस्तों के साथ खेल सकते हैं!

## 📋 विवरण

यह एक **interactive Ludo game** है जो Java में develop किया गया है। इसमें आप:
- 🎮 Single और Multiplayer दोनों modes में खेल सकते हैं
- 🎯 पासे को roll करके अपने tokens को move कर सकते हैं
- 🏆 सबसे पहले सभी tokens को home में लाकर जीत सकते हैं

## 🚀 शुरुआत करें

### Requirements
- Java 8 या उससे ऊपर
- JDK (Java Development Kit) installed

### Installation

1. Repository को clone करें:
```bash
git clone https://github.com/dharmendragadari55555-crypto/Ludo-game-.git
cd Ludo-game-
```

2. Code को compile करें:
```bash
javac *.java
```

3. Game को run करें:
```bash
java LudoGame
```

## 🎮 कैसे खेलें?

1. Game शुरू करने के लिए `java LudoGame` run करें
2. अपने नाम enter करें
3. पासा roll करें (Dice roll करें)
4. अपने tokens को move करें
5. सबसे पहले सभी tokens को home में लाने वाला जीतता है! 🎉
